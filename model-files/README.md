# Model files

Phase 1 detector weights are downloaded and cached automatically by TorchVision.

Phase 2 currently uses `therealcyberlord/stanford-car-vit-patch16`. Hugging Face downloads and caches its weights automatically, so this directory remains empty.

A future fine-tuned replacement can place exported weights and label metadata here. Large weight files are ignored by Git and should be distributed through release or model-hosting storage.
